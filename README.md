# Neovim configuration

My personal Neovim configuration, managed with [lazy.nvim](https://github.com/folke/lazy.nvim).

## Install

Clone this repository to Neovim's config directory:

```sh
git clone https://github.com/maulairfani/nvim.git ~/.config/nvim
```

Open Neovim to bootstrap lazy.nvim and install the plugins. Plugin versions are recorded in `lazy-lock.json`.
